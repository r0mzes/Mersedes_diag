# Блок vito_diag на ESP32: схема и спецификация (шаг 2)

Схема: [schematic.svg](schematic.svg) (картинка — [schematic.png](schematic.png)), список для заказа —
[bom.csv](bom.csv). Блок заменяет Uno + реле + ELM327: K-line делает микросхема L9637D, CAN —
SN65HVD230, Wi-Fi и приборка — ESP32 (прошивка `firmware/esp32_obd_panel`, docs/ESP32_PANEL.md).
Только чтение.

> Замена против первого списка: вместо модуля **MP1584** — **LM2596**. У MP1584 предел входа 28 В, а
> защитный диод SMBJ24A при выбросе в бортсети ограничивает лишь до ~39 В. LM2596 держит до 40 В.

## Подключение

| Откуда | Куда |
|---|---|
| OBD 16 (+12 В) | F1 1 А → (TVS SMBJ24A катодом на эту точку, анодом на массу) → SS34 (анод к F1) → **VBAT_P** |
| VBAT_P | 100 мкФ + 100 нФ на массу; вход LM2596; L9637D вывод 7 (VS); R 510 Ом 1 Вт → K L9637D |
| OBD 4, 5 | общая масса: минусы LM2596, L9637D (5), модулей, GND ESP32 |
| LM2596 выход (выставить **5,0 В** до подключения!) | **+5V**: ESP32 VIN, L9637D вывод 3 (VCC), HV преобразователя уровней, JD-VCC реле |
| ESP32 3V3 | **+3V3**: LV преобразователя, 3V3 SN65HVD230, VCC (оптроны) модуля реле |
| L9637D 4 (TX) | HV1 ↔ LV1 ↔ ESP32 **GPIO17** (UART2 TX) |
| L9637D 1 (RX) | HV2 ↔ LV2 ↔ ESP32 **GPIO16** (UART2 RX) |
| L9637D 6 (K) | COM реле R3 (**K_SEL**) |
| Реле R1 (IN1 ← GPIO25) | NC ← OBD 7, NO ← OBD 8, COM → X |
| Реле R2 (IN2 ← GPIO26) | NC ← OBD 9, NO ← OBD 11, COM → Y |
| Реле R3 (IN3 ← GPIO27) | NC ← X, NO ← Y, COM → K_SEL |
| SN65HVD230 CTX / CRX | ESP32 **GPIO14** / **GPIO15** (как в firmware/esp32_can_adapter) |
| SN65HVD230 CANH / CANL | OBD 6 / OBD 14 (витая пара). **Снять резистор 120 Ом на модуле** |
| Делители 100 кОм / 22 кОм + 10 нФ | OBD 16 → GPIO32, 7 → GPIO33, 8 → GPIO34, 9 → GPIO35, 11 → GPIO36, 6 → GPIO39 |

Замечания:

- Без питания все реле отпущены и на L9637D идёт контакт 7, как в нынешнем obd_hub.
- Входы реле включаются нулём. Прошивка в `setup()` сразу ставит HIGH на 25/26/27, иначе при старте
  реле щёлкнут.
- Для АЦП только АЦП1 (GPIO32–39): АЦП2 при включённом Wi-Fi не работает.
- Делитель 100/22 даёт 2,9 В при 16 В. Выброс до ~39 В (после TVS) даст на входе ~7 В через 100 кОм,
  ток ~0,3 мА. Обычно ESP32 это переживает, но с BAT54S спокойнее.
- Мощность резистора 510 Ом: когда K-line прижата к массе, на нём ~0,4 Вт, поэтому 1 Вт.
- Неиспользуемые выводы L9637D (2 LO, 8 LI): подключение **сверить с даташитом** до пайки.

## Порядок сборки и проверки

1. LM2596 от лабораторного блока 12 В: выставить 5,0 В без нагрузки.
2. Собрать питание (F1, TVS, SS34, конденсаторы). Проверить: +12 → 5,0 В; переполюсовка → сгорает F1.
3. ESP32 + преобразователь уровней + L9637D на столе, K через 510 Ом к 12 В. Осциллографом или
   мультиметром: в покое на K ~12 В.
4. Реле и делители. В машине сначала замер (`~STATE` покажет напряжения после доработки прошивки),
   потом опрос.
5. CAN — последним (снять 120 Ом!).

Прошивку для своего K-line (шаг 2) сделаю, когда детали будут на руках: инициализацию 10400 бод
(быстрая 25 мс / 25 мс и 5-бод) проверим сначала на эмуляторе, потом на «Январе».
