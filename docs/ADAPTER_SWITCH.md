# Переходник-переключатель K-line для Vito W639

## Зачем он нужен

В разъёме OBD вашей машины (по фото) заняты контакты **4, 5, 6, 7, 8, 9, 11, 14, 16**:

| Контакт | Назначение |
|---|---|
| 4, 5 | масса |
| 16 | +12 В |
| 6, 14 | CAN (стандартная) |
| 7 | K-line (стандартная) |
| **8, 9, 11** | **дополнительные линии Mercedes** к отдельным блокам |

Адаптер ELM327 работает с K-line только через контакт 7. Переходник позволяет
переключателем подать на контакт 7 адаптера **любой** из контактов машины: 7, 8, 9 или 11.
Так программа сможет найти блоки на каждой линии по очереди.

> Нумерация контактов определена по фото и логике (разъём у Vito стоит «вверх ногами»).
> Шаг 1 ниже заодно проверяет, что нумерация верна.

---

## Шаг 1. Сначала измерить (5 минут, нужен только мультиметр)

Так мы узнаем, что на контактах 8, 9, 11: K-line (тогда подходит этот переходник)
или вторая CAN (тогда схему надо изменить).

1. Включите зажигание, двигатель не заводите.
2. Мультиметр — режим постоянного напряжения, предел 20 В.
3. Чёрный щуп — на контакт **4** (или на «массу» кузова).
4. Красным щупом касайтесь по очереди контактов из таблицы. Нужен **тонкий** щуп
   (иголка, тонкая скрепка), чтобы не замкнуть соседние контакты.
   **Осторожно с контактом 16 (+12 В):** не замкните его на соседние.

| Контакт | Ожидаемо | Ваш замер |
|---|---|---|
| 16 | ~12 В (питание) | |
| 5 | 0 В (масса) | |
| 6 | ~2,5 В (CAN-H) | |
| 14 | ~2,5 В (CAN-L) | |
| 7 | ~12 В или 0 В (K-line) | |
| 8 | ? | |
| 9 | ? | |
| 11 | ? | |

Как понимать результаты:
- **около 12 В** (или чуть ниже напряжения АКБ) — скорее всего K-line, переходник подходит;
- **около 2,5 В на двух контактах** — вторая шина CAN, нужна другая схема (напишите, подготовлю);
- **0 В** — линия, возможно, активируется только при опросе, это тоже нормально для K-line.

Если на 16 **нет** 12 В, а на каком-то другом контакте есть — значит, нумерация перевёрнута.
Тогда сообщите замеры, и я пересчитаю схему.

## Шаг 2. Что купить

| Деталь | Примечание |
|---|---|
| **Удлинитель OBD2 «папа — мама», все 16 проводов** | Проверьте мультиметром (прозвонкой), что проводами соединены хотя бы контакты 4, 5, 6, 7, 8, 9, 11, 14, 16. В дешёвых удлинителях бывает не 16 проводов. |
| **Поворотный переключатель 1 направление × 4 положения** (1P4T), например серии SR26 / RS26 | Подойдёт и 1P12T с ограничителем. Нужен переключатель **без перекрытия** (non-shorting): такие обычно и продаются. Два положения никогда не должны быть соединены одновременно. |
| Термоусадка, небольшая коробочка, паяльник | |
| Бумажные наклейки / маркер | Подписать положения: 7, 8, 9, 11 |

Отдельные тумблеры вместо поворотного переключателя **не** используйте: легко включить
два сразу и соединить две линии разных блоков.

## Шаг 3. Схема

Со стороны «папа» кабель вставляется в машину, со стороны «мама» — в ELM327.

```
   МАШИНА (вилка «папа»)                          ELM327 (розетка «мама»)

   4, 5, 6, 14, 16 и прочие ─────────────────────── те же контакты (не трогаем)

                         Переключатель 1P4T
   конт. 7  ─────────── положение 1 ─┐
   конт. 8  ─────────── положение 2 ─┤
   конт. 9  ─────────── положение 3 ─┼── общий ──── конт. 7
   конт. 11 ─────────── положение 4 ─┘

                                                    конт. 8, 9, 11 — концы изолировать
                                                    (к адаптеру не подключать)
```

Проще говоря, **перерезаются только 4 провода: 7, 8, 9 и 11**. Остальные идут
насквозь, как были.

### Порядок работы

1. Прозвоните удлинитель: найдите, какого цвета провод у контактов 7, 8, 9 и 11.
   Запишите на бумажке. Цвета у разных производителей разные.
2. Аккуратно разрежьте оболочку посередине кабеля и перережьте **только** эти 4 провода.
3. Концы со стороны **вилки «папа»** (машина):
   7 → положение 1, 8 → положение 2, 9 → положение 3, 11 → положение 4.
4. Конец провода **7** со стороны **розетки «мама»** (ELM327) → общий вывод переключателя.
5. Концы проводов 8, 9, 11 со стороны «мамы» заизолируйте термоусадкой.
6. Все пайки заизолируйте, уложите переключатель в коробочку, подпишите положения.

### Проверка перед подключением к машине (обязательно)

Мультиметр в режиме прозвонки, удлинитель ни к чему не подключен:
- в положении «7» контакт 7 «мамы» звонится с контактом 7 «папы» и **не** звонится с 8, 9, 11;
- так же для положений 8, 9, 11;
- контакт **16 не звонится ни с одним другим** (иначе — замыкание +12 В);
- 4, 5, 6, 14, 16 звонятся насквозь.

## Шаг 4. Использование

1. Переключатель в положение **7** (стандартное) — `scan` и обычная диагностика работают как без переходника.
2. Сканируем каждую линию, **указывая программе положение переключателя**:
   ```
   python -m vito_diag ecu scan-all   --port COM3 --line 7
   python -m vito_diag ecu scan-kline --port COM3 --line 8
   python -m vito_diag ecu scan-kline --port COM3 --line 9
   python -m vito_diag ecu scan-kline --port COM3 --line 11
   ```
   Переключать можно только между запусками программы, не во время сканирования.
3. После диагностики верните переключатель в положение **7**.

Если работаете с Claude Code на ноутбуке, Claude сам скажет, в какое положение
поставить переключатель, и запустит нужные команды.
