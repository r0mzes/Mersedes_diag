# Распайка переключателя линий OBD

> Старый вариант (ESP32-CAM + плата реле LC X4, 2026-10-03). Плата LC не заработала, вариант отложен;
> текущая сборка — Arduino Uno + HC-06, см. [AUTO_SWITCH.md](AUTO_SWITCH.md). Файл перенесён с домашнего ПК (папка Mersedes-fiag).

ESP32-CAM по Bluetooth управляет платой реле LC X4 (12 В). Реле подают на контакт 7 адаптера один из контактов машины: 7, 8, 9 или 11. Без питания всё работает как обычный удлинитель.

K-line (7, 8, 9, 11) +12 В (контакт 16) масса 5 В и управление замер ● точка — соединение; пересечение без точки — провода не соединены

**Не соединяйте COM нескольких реле вместе.** Только «дерево», как на схеме: реле 1 и 2 выбирают из пары, реле 3 выбирает между ними. Тогда на контакт 7 адаптера физически попадает один контакт машины, даже если программа ошибётся.

## Провода по порядку

| Откуда | Куда |
| --- | --- |
| Машина 7 | Реле 1, NC |
| Машина 8 | Реле 1, NO |
| Машина 9 | Реле 2, NC |
| Машина 11 | Реле 2, NO |
| Реле 1, COM | Реле 3, NC |
| Реле 2, COM | Реле 3, NO |
| Реле 3, COM | Адаптер 7 |
| Машина 16 | Предохранитель 1 А, дальше на IN+ и на реле 4, COM |
| Реле 4, NC | Адаптер 16 (NO не подключать) |
| Машина 4 | IN−, GND ESP32-CAM, нижние концы 18 кОм |
| Плата реле 5V | ESP32-CAM 5V |
| Плата реле GND | ESP32-CAM GND |
| Плата реле RX | ESP32-CAM IO14 |
| Машина 8, 9, 11 | 100 кОм → IO2, IO13, IO15; от каждого входа 18 кОм на массу |

## Какое реле включено

| Линия | Реле 1 | Реле 2 | Реле 3 |
| --- | --- | --- | --- |
| 7 | — | — | — |
| 8 | вкл | — | — |
| 9 | — | — | вкл |
| 11 | — | вкл | вкл |

Реле 4 включается только по команде `PWR OFF`, чтобы обесточить зависший адаптер.

## Перед машиной

- Удлинитель прозвонить: все 16 проводов, цвета проводов 7, 8, 9, 11, 16 записать.
- Резать только 7, 8, 9, 11 и 16. Провод 4 не резать, массу взять отводом.
- Без питания: контакт 7 «мамы» звонится только с 7 «папы», 16 — только с 16.
- Контакт 16 не звонится ни с одним другим контактом.
- Первый запуск на столе: плату реле от блока питания 12 В, машина не нужна.
- ESP32-CAM прошивать на программаторе отдельно, потом ставить в коробку.
