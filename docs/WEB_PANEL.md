# Приборка в браузере и на телефоне

`python -m vito_diag web` поднимает на ноутбуке страницу с живыми данными. Её можно открыть в браузере
ноутбука или на телефоне в той же Wi-Fi сети (адрес программа печатает при запуске). Только чтение.

```
python -m vito_diag web --port COM7 --hub COM4        # ВАЗ «Январь» (K-line, контакт 7)
python -m vito_diag web --profile obd --port COM7     # общий OBD-II (Mercedes и др.)
python -m vito_diag web --demo                        # эмулятор «Января» с переливом (без машины)
python -m vito_diag web --demo ok                     # эмулятор исправного мотора
```

В окне (`gui_windows.bat`) то же самое: кнопки «📱 Панель в браузере» (вкладка ВАЗ) и
«📱 Приборка в браузере» (вкладка Mercedes); с галкой «Демо» — эмулятор.

## Как устроено

Транспорт (COM-порт / эмулятор) → `ElmLink` или python-OBD → профиль машины (`vito_diag/live.py`:
`LadaProfile`, `ObdProfile`) → `Poller` → веб-сервер (`vito_diag/web.py`, без сторонних библиотек) →
страница `vito_diag/data/panel.html`.

- `Poller` опрашивает профиль в своём потоке. При обрыве закрывает связь и переподключается
  (пауза 1, 2, 4 … 10 с). Наверху страницы видно состояние: зелёный — на связи, жёлтый — подключение,
  красный — связь потеряна.
- У каждого значения есть время замера: если замера нет дольше 5 с, плитка бледнеет и пишет
  «устарело», цифры не застывают молча.
- Плитки выбираются кнопкой «Плитки», выбор запоминается в браузере. Вне нормы на заведённом моторе
  (ОЖ, коррекции, напряжение) цифра красная.
- Каждый замер пишется в `reports/<профиль>_live_*.csv`.
- Эмулятор (`vito_diag/emulator.py`) подставляется вместо COM-порта, поэтому демо проходит через тот же
  код протокола, что и машина: инициализация K-line, 1A 80, 18 00, служба 01.

## Если телефон не открывает страницу

- Телефон и ноутбук должны быть в одной сети Wi-Fi.
- При первом запуске Windows спросит про брандмауэр: разрешите Python для частной сети.
- Сеть в Windows должна быть «Частная», а не «Общедоступная».
