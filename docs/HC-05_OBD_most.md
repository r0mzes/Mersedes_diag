# Bluetooth-мост HC-05 + Arduino для ELM327

Идея: Arduino служит простым переходником USB–UART, а HC-05 в режиме «ведущего» (master) сам подключается к Bluetooth в адаптере OBD. Компьютер видит обычный COM-порт Arduino.

```
Ноутбук --USB--> Arduino (только USB-UART) --провода--> HC-05 ~~Bluetooth~~> адаптер ELM327 --> машина
```

Подойдут Arduino Uno, Nano или Mega. Leonardo и Pro Micro так не работают. STM32 не нужен.

## 1. Arduino превращаем в переходник

Перемычкой соедините контакты **RESET** и **GND** на Arduino. Процессор Arduino будет выключен, и останется только её USB-UART чип. Скетч заливать не нужно.

## 2. Подключение HC-05

| HC-05 | Arduino |
|---|---|
| +5V (VCC) | 5V |
| GND | GND |
| TXD | **D1 (TX)** |
| RXD | **D0 (RX)** через делитель: D0 → резистор 1 кОм → RXD, и от RXD резистор 2 кОм на GND |
| EN (KEY) | пока не подключать |
| STATE | не нужен |

Да, здесь TX идёт на TX, а RX на RX: при перемычке RESET–GND так и должно быть. Делитель нужен, потому что вход RXD у модуля рассчитан на 3,3 В.
Если нет резистора 2 кОм, поставьте два по 1 кОм последовательно.

## 3. Режим AT-команд

1. Отключите USB от Arduino.
2. Зажмите кнопку на HC-05 (или подайте 3,3 В на EN) и, не отпуская, вставьте USB. Кнопку можно отпустить через 2 секунды.
3. Светодиод должен мигать **медленно**, примерно раз в 2 секунды. Это режим AT.
4. В Arduino IDE откройте «Монитор порта»: скорость **38400**, окончание строки **«NL & CR»** (обе).

## 4. Настройка HC-05

Вводите команды по одной, на каждую должно прийти `OK`:

```
AT
AT+ORGL
AT+ROLE=1
AT+CMODE=0
AT+PSWD="1234"
AT+UART=38400,0,0
AT+INIT
```

- Если на `AT+PSWD="1234"` пришла ошибка, введите без кавычек: `AT+PSWD=1234`.
- Если на `AT+INIT` пришло `ERROR:(17)`, всё нормально, модуль уже инициализирован.
- Если `AT+ROLE=1` не принимается совсем, это HC-06. Он не умеет быть ведущим, нужен HC-05.

## 5. Находим адаптер OBD

Вставьте адаптер в машину, включите зажигание и **отключите его от телефона**.

```
AT+INQM=0,5,9
AT+INQ
```

Придут строки вида `+INQ:1234:56:ABCDEF,...`. Адрес здесь `1234:56:ABCDEF`. Для каждого адреса имя можно узнать так (двоеточия замените на запятые):

```
AT+RNAME?1234,56,ABCDEF
```

Найдите адаптер (OBDII, OBD2, V-LINK и т.п.) и выполните с его адресом:

```
AT+PAIR=1234,56,ABCDEF,20
AT+BIND=1234,56,ABCDEF
AT+LINK=1234,56,ABCDEF
```

Если `PAIR` не проходит, у адаптера другой PIN: поставьте `AT+PSWD="0000"` и повторите.

## 6. Обычная работа

1. Выньте USB и вставьте снова, **без** нажатой кнопки.
2. HC-05 сам подключится к адаптеру. Светодиод будет давать двойные вспышки раз в пару секунд.
3. В Диспетчере устройств посмотрите номер COM-порта Arduino. Это и есть порт адаптера, скорость **38400**.
4. Проверка в мониторе порта (38400, NL & CR): `ATZ` должен ответить `ELM327 v1.5`, а `ATI` — версией.
5. После этого запускайте vito_diag с этим COM-портом.
