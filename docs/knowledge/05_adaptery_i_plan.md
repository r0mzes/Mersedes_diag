# Чем можно прочитать больше блоков: варианты и план

## 1. Проверить, какой у нас чип (5 минут)
По cvtz50.info: настоящий ELM327 v1.5 — PIC18F25K80 с кварцем 4 МГц; подделки (STM32F042, YM1130,
BK3231Q под компаундом) тоже называют себя «v1.5». Простой тест: команда `ATPPS` — настоящий отвечает
списком параметров, подделка — `?`. Через мост: `tools/esp_terminal.ps1 -Port COMx -Lines "ATPPS"`.
Наш адаптер почти наверняка подделка (игнорирует `ATSH`, нет `ATFI`/`ATSI`, `ATCAF0` → ошибка).

## 2. Нормальный ELM-совместимый адаптер (дёшево, vito_diag уже умеет)
Нужно: выполняет `ATSH`/`ATCRA`, принимает многокадровые ответы, умеет `ATFI`/`ATSI`.
Подходят OBDLink (чип STN), vLinker, Vgate iCar Pro — их cvtz50 называет «обычно хорошими».
Что это даст на W639: перебор CAN ID на 6/14 (vito_diag уже умеет, клон просто не даёт), полную
идентификацию АКПП, адресный опрос K-line на 7 и через переключатель на 9/11.
Чего не даст: блоки за шлюзом EZS, если им нужен особый «пробуждающий» кадр и свои ID — их ID для W639
неизвестны без DAS.

## 3. Свой интерфейс на ESP32 (у пользователя есть ESP32-S3 и ESP32-CAM) — вывод, не проверено
- **CAN:** в ESP32 встроен CAN-контроллер (TWAI). Нужен только модуль-трансивер SN65HVD230 (3,3 В)
  на контакты 6/14. Полный контроль: любой ID запроса, свой Flow Control (многокадровые ответы),
  режим «только слушать» для безопасного начала. Есть библиотека ESP32 TWAI ISO-TP
  (https://www.arduinolibraries.info/libraries/esp32-twai-iso-tp).
- **K-line:** микросхема L9637D / MC33290 (или схема на транзисторе) к UART ESP32. 5-бод и быстрая
  инициализация программно, на любой адрес — то, чего не умеет клон. Вместе с переключателем линий
  это даёт честный перебор адресов на 7/9/11.
- Правило проекта сохраняется: только сервисы чтения (`1A`, `18`, `21`, `3E`).

## 4. «Как у сервиса»: DAS/Xentry
- W639 2003–2010 — это эпоха DAS (файлы CBF). Обычный путь — клон **SD Connect C4** + DAS/Xentry:
  видит все блоки, коммутирует K-линии по контактам сам.
- Дешевле: J2534-адаптер (Tactrix OpenPort 2.0, Mini VCI, VXDIAG) + **Xentry Passthru**. В обзорах
  пишут, что passthru хуже работает со старыми машинами; на W639 нужны и K-линии на разных контактах —
  стандартный J2534 даёт K-line только на 7 (вывод по стандарту, на W639 не проверено).
- Через passthru можно снять реальные ID блоков W639: rnd-ash показывает, как прочитать журнал
  обмена Xentry (`activity.log` у Macchina) — после этого те же запросы можно повторить своим адаптером.

## Рекомендуемый порядок
1. Не трогать линию 8 до замера; проверить, жив ли адаптер на линии 7.
2. Замер напряжений 7/8/9/11/16 при выключенном и включенном зажигании (04_linii_8_9_11.md).
3. `ATPPS` — убедиться, что чип поддельный.
4. Выбор: купить OBDLink/vLinker **или** собрать CAN на ESP32 + SN65HVD230 (дешевле, но больше работы).
5. Для полного списка блоков и номеров деталей — один сеанс DAS/Xentry у знакомых или в сервисе;
   записать ответ в CLAUDE.md «Найденные блоки».
