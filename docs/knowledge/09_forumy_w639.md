## 2. Блоки W639 (каталог StarCOM, obdtester.com)

Список блоков W639, которые поддерживает StarCOM (как именуются в диагностике):
- двигатель: CR3 Bosch EDC16C2 (варианты KWP2000 или CAN); **CR4 Bosch EDC16C31 — KWP2000 (= OM646)**;
- **EGS_639 — K-LINE** [?]; EWM_639 — модуль селектора;
- KI639 (приборка) — CAN или KWP2000; KLAV_639 (климат) — K-line или CAN;
- PTS 639 (парктроник) — KWP2000; DBE/TSG (двери) — KWP; ESP8 639.
[?] «EGS_639 по K-line» расходится с нашим замером (EGS отвечает на CAN 0x7E1/0x7E9). Вывод: у EGS могут быть оба
канала (K-line на pin 11 или 9 и CAN), либо по CAN отвечает только OBD-часть. Сходится с LogNet (07 §1.1):
диагностика кулисы → pin 9.

## 3. EZS — шлюз (форумные выдержки через поиск, страницы недоступны) [?]

- Разъём B EZS W639: **4 — K-line**, **5/6 — CAN-C (двигатель) L/H**, **7/8 — CAN-B (салон) L/H**.
- Приборка, разъём 1: 1/2 — CAN-C H/L, 3/4 — CAN-B.
- Вывод: EZS соединяет CAN-C, CAN-B и K-line — совпадает с «три CAN в EZS» (07 §2).
- Кадр «пробуждения» шлюза и CAN ID блоков W639 в открытых источниках **не найдены** (ср. 08 §5 — таблица для W203/W211).
- mbclub.co.uk 187439 (2015): случай «не заводится» из-за EZS, без технических данных.

## 4. K-line протокол (Sprinter T1N, sprinter-source)

- Тема 18584 (seccoxiru, 2011): KWP2000, **10400 бод**, live data сервисом **0x22** с ID `1D02 1D05 1D07–1D0A 1D0E`
  (формулы не опубликованы). https://sprinter-source.com/forums/index.php?threads/18584/
- Тема «OBD Hacking» p=444602 (seans, 2016): **fast init 25/25 мс**; **адрес тестера Mercedes 0xF2** (не 0xF1);
  догреватель (Webasto) на адресе **0xB0**. https://sprinter-source.com/forum/showthread.php?p=444602
- Адрес двигателя 0x12 в источниках не подтверждён и не опровергнут (у нас он отвечает).
- Вывод для vito_diag: при ошибках связи попробовать адрес тестера F2 (`ATTA F2`) — только чтение.

## 6. Адаптеры и программы

- Полный доступ — Xentry/DAS с SD Connect C4/C6. Больше, чем ELM327, читают iCarsoft MB II, Autel MD804, CDP+/Autocom
  (mbclub.co.uk 236386, 2018; drive2 Valdr 2018). ELM327 на W639 работает плохо — совпадает с нашим опытом.
