# Протоколы и инициализация: K-line и KWP2000 у Mercedes

## K-line (ISO 9141-2 / ISO 14230 «KWP2000»)
- Однопроводная, 10 400 бод; в покое линия подтянута к напряжению АКБ (~12 В), «0» — около массы.
- Сообщение до 255 байт; ECU засыпает примерно через 5 с тишины — нужен TesterPresent (`3E`).
- **Быстрая инициализация (fast init):** 25 мс «0», 25 мс «1», затем StartCommunication
  `81` с заголовком «формат / адрес блока / адрес тестера». Если адрес в заголовке не тот — блок молчит.
- **5-бод (slow init):** адрес блока передаётся на скорости 5 бод (~2 с), блок отвечает `55`
  (синхронизация) и двумя ключевыми байтами, тестер возвращает инверсию второго, блок — инверсию адреса.
  Тайминги из rnd-ash: 200 мс low, 400 high, 400 low, 400 high, 400 low, 200 high (пример байта).
- Mercedes нередко отдаёт нестандартные ключевые байты — поэтому в vito_diag стоит `ATKW0`.

## Команды ELM327, которые для этого нужны (по даташиту Elm Electronics)
| Команда | Что делает | Наш клон |
|---|---|---|
| `ATSP4` / `ATSP5` | ISO 14230 с 5-бод / быстрой инициализацией | работает |
| `ATSH 81 xx F1` | заголовок: адрес блока xx | **игнорирует** |
| `ATIIA xx` | адрес для 5-бод инициализации | не проверено отдельно, вероятно игнорирует |
| `ATSI` / `ATFI` | выполнить 5-бод / быструю инициализацию | `?` (нет) |
| `ATKW0` | не проверять ключевые байты | работает |
| `ATWM …` | своё сообщение «поддержания связи» | работает (не проверено, что применяется) |
| `ATSH 7E0` + `ATCRA 7E8` | CAN: ID запроса и фильтр ответа | **игнорирует** |
| `ATCAF0`, `ATFC…` | ручная работа с ISO-TP / flow control | `CAN ERROR` |

## KWP2000 у Mercedes — сервисы, которые нам нужны (только чтение)
- `1A 86` / `1A 87` / `1A 90` — идентификация (номер детали, версия, VIN).
- `18 02 FF 00` или по группам `18 02 0000/4000/8000/C000 00` — ошибки (ReadDTCByStatus).
  Проект WiCAN читает так же 18 блоков Sprinter W906 (там старые блоки на KWP, новые на UDS `19 02`).
- `21 xx` — данные по локальному идентификатору; `22 xxxx` — по общему (Sprinter: `1D02`, `1D05`…
  дают обороты, температуру — форум MBWorld, расшифровка не опубликована).
- `3E` — TesterPresent.
- `10 92` встречается как «пробуждающий» кадр для шлюза W203/W211 (ID 0x01C). Это смена сессии —
  по правилам проекта без явной просьбы не отправлять.

## KWP2000 на CAN
- Тот же набор сервисов, но поверх ISO 15765-2 (ISO-TP): длинные ответы делятся на кадры, тестер
  обязан ответить кадром Flow Control (`30 …`). Пример из диссертации rnd-ash (W203, CAN-B):
  первый кадр `10 12 03 26 …` на 0x1A4 → flow control `30 08 28` на 0x1D0 → кадры `21 …`, `22 …`.
- Наш клон flow control не шлёт — поэтому идентификация АКПП обрезана на первом кадре.
