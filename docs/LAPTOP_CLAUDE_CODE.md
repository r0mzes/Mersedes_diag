# Claude Code на ноутбуке: Claude сам опрашивает машину

Схема работы:

```
Vito ── OBD ── переключатель ── ELM327 (USB) ── ноутбук: Claude Code + vito_diag
                                                   │
                                          интернет (раздача с телефона)
```

Claude Code на ноутбуке запускает команды программы, видит ответы блоков в логах,
дорабатывает программу и говорит вам, когда перевести переключатель.

## 1. Установка (дома, один раз)

1. **Python 3.9+** — https://www.python.org/downloads/ (отметить «Add Python to PATH»).
2. **Git для Windows** — https://git-scm.com/download/win (нужен и для проекта, и для Claude Code).
3. **Claude Code.** Актуальная инструкция: https://code.claude.com/docs/en/setup.
   На Windows обычно достаточно выполнить в PowerShell:
   ```powershell
   irm https://claude.ai/install.ps1 | iex
   ```
4. **Проект:**
   ```powershell
   cd $HOME
   git clone https://github.com/r0mzes/Mersedes_diag.git
   cd Mersedes_diag
   git checkout claude/mercedes-vito-diagnostics-1fgsio
   .\install_windows.bat
   ```
5. Запустите `claude` в папке проекта и войдите в свой аккаунт.
   Claude прочитает файл `CLAUDE.md` с описанием машины и проекта.
6. Проверка без машины: попросите Claude «запусти демо-скан».

## 2. Драйвер адаптера (дома)

Вставьте USB ELM327 в ноутбук → «Диспетчер устройств → Порты (COM и LPT)».
Должен появиться COM-порт. Если нет — драйвер CH340 или FTDI (см. README).

## 3. У машины

1. Если возможно, подключите к АКБ зарядное устройство: опрос с включённым
   зажиганием занимает десятки минут.
2. Раздайте интернет с телефона на ноутбук.
3. Переходник → в OBD-разъём, ELM327 → в переходник, USB → в ноутбук. Переключатель — в положение **7**.
4. Включите зажигание, двигатель не заводите.
5. В папке проекта запустите `claude` и напишите, например:
   > Машина подключена, переключатель на 7, порт COM3. Опроси все блоки.

## Безопасность

- Программа **только читает**. Запросы стирания ошибок, записи, сброса блоков и прошивки
  заблокированы (их пропускает только флаг `--unsafe`).
- Claude не стирает ошибки и не использует `--unsafe` без вашего явного разрешения.
- Переключатель переводите только между запусками команд, когда Claude попросит.
- Если на приборке что-то необычное или пропала связь — выключите зажигание на 10 секунд,
  это сбрасывает сеансы связи.
