# Общий блок OBD: CAN + переключатель линий на Arduino Uno

Один Arduino Uno по USB делает всё, что раньше делали переключатель на HC-06 и отдельный
CAN-адаптер:

- **CAN (OBD 6/14)** через модуль MCP2515 + TJA1050: свой ID запроса (`ATSH`), фильтр ответа (`ATCRA`),
  длинные ответы целиком (Flow Control), прослушивание шины. Для vito_diag это ELM327 «vito-can».
- **Реле линий K-line**: контакт 7 / 8 / 9 / 11 машины на контакт 7 адаптера ELM327 («дерево»).
- **Реле питания ELM327** и **замер напряжений** на контактах 16, 7, 8, 9, 11, 6.

K-line сам блок не читает: двигатель и линии 8/9/11 по-прежнему опрашивает ELM327 через мост ESP32.

```
                 ┌─ CAN 6/14 ── MCP2515 ─┐
 Машина ── удлинитель ── реле 7/8/9/11 ───┼── Arduino Uno ── USB ── ноутбук: --hub COM4
                 └─ ELM327 ~~Bluetooth~~ мост ESP32 ── ноутбук: --port COM7 (K-line)
```

Схема с проводами: https://claude.ai/artifact/KquWiXCY8LeZde2erXKFq6 (частная, открывается у владельца).

## Подключение

| Что | Куда |
|---|---|
| MCP2515 VCC / GND | Uno 5V / GND |
| MCP2515 CS / SI / SO / SCK | Uno D10 / D11 / D12 / D13 (INT не нужен) |
| MCP2515 H / L | отводы от проводов 6 / 14 удлинителя (провода не резать) |
| Реле 1, 2, 3, 4 (IN) | Uno D2, D3, D4, D7 (как в AUTO_SWITCH.md) |
| «+» / «−» модулей реле | Uno 5V / GND |
| Машина 4 | GND Uno |
| Делители 10 кОм / 2,2 кОм | 16→A0, 7→A1, 8→A2, 9→A3, 11→A4, 6→A5 |

- Перемычку **J1** на модуле MCP2515 не ставить: это резистор 120 Ом, шина в машине уже нагружена
  (между 6 и 14 при выключенном зажигании около 60 Ом).
- Кварц X1: прошивка написана под **8 МГц** (надпись 8.000). Если на кварце 16.000 — в начале
  `obd_hub.ino` поменять `MCP_8MHZ` на `MCP_16MHZ`.
- Шилд с HC-06 снять: D0/D1 заняты USB. Блок питается от USB ноутбука, DC-DC не нужен.
  Контакт 16 (+12 В) на Uno и MCP2515 не подавать.

## Прошивка

1. Arduino IDE → Управление библиотеками → **autowp-mcp2515** (автор autowp).
2. Открыть `firmware/obd_hub/obd_hub.ino` (рядом должен лежать `elm_can_core.h`), плата «Arduino Uno».
3. Загрузить. Порт — 115200.

## Как пользоваться

```
python -m vito_diag switch meas --switch COM4                     # замеры (как раньше)
python -m vito_diag switch sel 9 --switch COM4                    # выбрать линию
python -m vito_diag ecu monitor --hub COM4                        # послушать CAN (ничего не передаёт)
python -m vito_diag ecu read --hub COM4 --can 7E1:7E9             # АКПП целиком
python -m vito_diag ecu scan-can --hub COM4                       # поиск блоков на CAN
python -m vito_diag ecu scan-all --hub COM4 --port COM7 --line 7,8,9,11   # CAN + K-line по всем линиям
```

С `--hub` CAN идёт через блок, K-line — через адаптер на `--port`, реле блок переключает сам между
опросами (мгновенно, по кабелю). `--switch` вместе с `--hub` не нужен.

## Протокол

Один порт, две «грамматики» по символу конца строки:

- строка с `\r` — команда ELM327 (`ATZ`, `ATSH7E1`, `1A86`, `ATMA`…), ответ кончается `>`;
- строка с `\n` — команда переключателя: `ID` → `OBDSW 2 HUB`, `SEL 9`, `PWR OFF`, `STATE`, `MEAS`, `RESET`.

Ограничения Uno (2 КБ памяти): длинный ответ до 200 байт (больше — помечается как обрезанный),
между кадрами длинного ответа адаптер просит паузу 1 мс. При включении и после `ATZ`/`ATPC` MCP2515
только слушает шину; если отправленный кадр никто не подтвердил, блок возвращается в этот режим.
