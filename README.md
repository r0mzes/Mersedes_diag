# vito_diag — диагностика Mercedes Vito 4x4 с ноутбука

Программа подключается к автомобилю через OBD-адаптер, считывает коды ошибок,
расшифровывает их на русском, группирует по системам, даёт рекомендации
«что проверить» и сохраняет отчёт (HTML + JSON). Может показывать и записывать
параметры двигателя в реальном времени.

```
Автомобиль (OBD-разъём) ──► адаптер ELM327 ──USB / Bluetooth / Wi-Fi──► ноутбук ──► vito_diag
```

---

## 1. Что купить

| Вариант | Что это | Что даёт |
|---|---|---|
| **USB ELM327** (рекомендую для начала) | Адаптер с USB-кабелем, 1000–2500 ₽. Лучше на чипе **FTDI** или с пометкой «PIC18F25K80 / v1.5». | Самое стабильное подключение к ноутбуку. |
| **Bluetooth ELM327** | То же, без провода. | Работает, но соединение иногда рвётся. |
| **Wi-Fi ELM327** | Адаптер создаёт свою Wi-Fi сеть. | Ноутбук отключается от интернета, пока подключён к адаптеру. |
| **OBDLink SX (USB) / OBDLink MX+** | Фирменные адаптеры, ~5–12 тыс. ₽. | Совместимы с ELM327, но быстрее и надёжнее. Лучший вариант, если бюджет позволяет. |

Дешёвые клоны «v2.1» за 300 ₽ часто глючат, особенно на CAN-шине, — их лучше не брать.

### Что увидит этот адаптер, а что нет

* ✅ **Блок двигателя (ЭБУ):** все ошибки по стандарту OBD-II (P0xxx, P2xxx, U0xxx):
  наддув, EGR, сажевый фильтр, свечи накала, топливо, датчики, AdBlue.
  Этого хватает для большинства проблем, при которых загорается **Check Engine**.
* ✅ Параметры в реальном времени: обороты, температура, наддув, давление топлива, напряжение.
* ⚠️ **Другие блоки (КПП, ESP, SAM...)** — экспериментально, командой `ecu`: поиск блоков на CAN и K-line
  и чтение их ошибок по KWP2000/UDS. Для K-line на нестандартных контактах Mercedes (8, 9, 11)
  нужен переходник с переключателем — см. [docs/ADAPTER_SWITCH.md](docs/ADAPTER_SWITCH.md).
* ❌ **ABS/ESP, раздаточная коробка 4MATIC, SAM, подушки, климат, приборка** — используют
  закрытые протоколы Mercedes. Для них нужен дилерский **Xentry/DAS** с адаптером
  **SD Connect C4/C5** (или клоном) либо мультимарочный сканер с поддержкой Mercedes
  (Autel MaxiCOM, Launch X431, iCarsoft MB). Если на приборке горит лампа ESP/ABS или
  сообщение о полном приводе, а `scan` ничего не показывает, — ошибка именно там.

## 2. Где разъём OBD в Vito

Разъём 16-контактный, трапециевидный, находится **под приборной панелью со стороны
водителя, слева от рулевой колонки** (на уровне коленей; иногда закрыт крышкой).
Ищите фонариком — он направлен вниз.

## 3. Установка на ноутбук

### Windows
1. Установите **Python 3.9+** с https://www.python.org/downloads/ —
   при установке обязательно отметьте **«Add Python to PATH»**.
2. Скопируйте папку проекта на ноутбук (или `git clone` репозитория).
3. Запустите двойным щелчком **`install_windows.bat`** — он создаст окружение,
   установит библиотеки и покажет демо-отчёт.
4. **Драйвер адаптера (для USB):** вставьте адаптер в ноутбук и откройте
   «Диспетчер устройств → Порты (COM и LPT)».
   * Если адаптер появился как `USB-SERIAL CH340 (COM3)` или `USB Serial Port (COM4)` — всё готово, запомните номер COM.
   * Если висит «Неизвестное устройство» — установите драйвер **CH340** или **FTDI VCP**
     (зависит от чипа; видно в свойствах устройства).
5. **Bluetooth-адаптер:** вставьте адаптер в машину, включите зажигание,
   на ноутбуке «Параметры → Bluetooth → Добавить устройство» → `OBDII`, PIN `1234`
   (или `0000`). Затем «Дополнительные параметры Bluetooth → COM-порты» — нужен
   **исходящий** COM-порт.

### Linux / macOS
```bash
./install_linux_mac.sh
# Linux: доступ к USB-порту без sudo
sudo usermod -aG dialout $USER   # затем перелогиниться
```
USB-адаптер появится как `/dev/ttyUSB0` (Linux) или `/dev/tty.usbserial-*` (macOS).
Bluetooth в Linux: `sudo rfcomm bind 0 <MAC-адрес>` → порт `/dev/rfcomm0`.

## 4. Подключение к машине — порядок действий

1. Вставьте адаптер в OBD-разъём (на адаптере загорится светодиод питания).
2. **Включите зажигание** (ключ в положение 2 / кнопка Start без нажатия тормоза).
   Для чтения ошибок двигатель заводить не нужно; для живых параметров — можно завести.
3. Подключите адаптер к ноутбуку (USB / Bluetooth / Wi-Fi).
4. Узнайте порт:
   ```bash
   python -m vito_diag ports
   ```
5. Считайте ошибки:
   ```bash
   python -m vito_diag scan --port COM3              # Windows
   python -m vito_diag scan --port /dev/ttyUSB0      # Linux
   python -m vito_diag scan --port socket://192.168.0.10:35000   # Wi-Fi адаптер
   python -m vito_diag scan                          # автопоиск порта
   ```
   На Windows можно просто запустить **`scan_windows.bat`**.

Отчёт сохраняется в папку `reports/` — откройте `.html` в браузере.

> **Важно:** не оставляйте адаптер в машине надолго при выключенном двигателе — он
> понемногу разряжает АКБ. Во время диагностики с заглушенным мотором лучше не
> включать фары/печку. Низкое напряжение само по себе вызывает ложные ошибки связи (U0xxx).

## 5. Команды

| Команда | Что делает |
|---|---|
| `python -m vito_diag ports` | Список COM-портов |
| `python -m vito_diag scan` | Ошибки (сохранённые + ожидающие), анализ, параметры, отчёт |
| `python -m vito_diag live --log drive.csv` | Параметры в реальном времени, запись в CSV (открывается в Excel) |
| `python -m vito_diag clear` | Стереть ошибки двигателя (с подтверждением) |
| `python -m vito_diag lookup P0299 P2463` | Расшифровать коды без подключения |
| `python -m vito_diag ecu monitor --port COM3` | Послушать шину CAN (ничего не отправляет) |
| `python -m vito_diag ecu scan-all --port COM3 --line 7` | Найти блоки на CAN и K-line, прочитать их ошибки |
| `python -m vito_diag ecu scan-kline --port COM3 --line 9` | Найти блоки на K-line (переключатель на контакте 9) |
| `python -m vito_diag ecu read --port COM3 --kline 10` | Идентификация и ошибки одного блока |
| `python -m vito_diag ecu raw "1A 86" --port COM3 --can 7E0` | Отправить свой запрос (только чтение) |

Добавьте `--demo`, чтобы попробовать команды scan/live/clear без машины, и `-v` — чтобы видеть
обмен с адаптером при проблемах подключения.

**Совет:** не стирайте ошибки сразу. Сначала сохраните отчёт, затем устраните
причину, сотрите и проедьте — если ошибка вернулась, проблема не решена.

## 6. Если не подключается

| Симптом | Что сделать |
|---|---|
| `ports` ничего не находит | Драйвер CH340/FTDI; для Bluetooth — сопряжение и исходящий COM-порт |
| «Не удалось связаться с автомобилем» | Включено ли зажигание? Горит ли светодиод на адаптере? Попробуйте `--baudrate 38400` или `--baudrate 9600` |
| Подключается к адаптеру, но не к машине | `--protocol 6` (CAN 11 бит 500 кбит/с) — стандарт для Vito примерно с 2008 г. |
| Ошибок нет, но лампа горит | Ошибка в блоке, недоступном по OBD-II (ABS/ESP/4MATIC/SAM) — нужен сканер Mercedes |
| Всё медленно / обрывы | Bluetooth-клон — попробуйте USB-адаптер |

## 7. Про Vito 4x4

> Памятка по конкретной машине (**W639 111 CDI 2008, OM646, АКПП 722.6**):
> [docs/W639_111CDI_2008.md](docs/W639_111CDI_2008.md). Для W639 до 2014 г. лучший способ
> читать **все** блоки — кабель **SD Connect C4** с программой DAS/Xentry.

* **W639** (2003–2014) — до 2010 г. OM646 (2.1 CDI: 109/111/115 CDI), после — OM651 (113/116 CDI); V6 OM642. Заводской 4x4 — примерно с 2010 г., раньше — переделки Oberaigner.
* **W447** (2014+, 4MATIC) — OM651, позже OM654.
* Частые ошибки этих моторов (есть в базе с пояснениями): наддув `P0299/P2263`,
  EGR `P0401`, сажевый фильтр `P2463/P2453`, свечи накала `P0380/P0670–P0674`,
  заслонки впускного коллектора `P2004–P2015` (OM646), цепь ГРМ/распредвалы `P0016`, AdBlue `P20EE/P203F` (Euro 6).
* Полный привод 4MATIC управляется отдельным блоком (раздатка + ESP) — его ошибки видны
  только сканером с поддержкой Mercedes.

## 8. Опрос всех блоков с помощью Claude Code на ноутбуке

См. [docs/LAPTOP_CLAUDE_CODE.md](docs/LAPTOP_CLAUDE_CODE.md) — как поставить Claude Code на ноутбук,
чтобы Claude сам опрашивал блоки через адаптер. Весь обмен с адаптером пишется в `logs/`.
Программа по умолчанию **только читает**: запросы стирания, записи, сброса и прошивки
блокируются (флаг `--unsafe` снимает защиту — не используйте его без крайней необходимости).

## 9. Структура проекта

```
vito_diag/
  cli.py          команды
  sources.py      подключение к машине (python-OBD) и демо-симулятор
  dtc.py          расшифровка кодов, загрузка базы
  data/dtc_ru.json  база кодов с описаниями и советами (можно дополнять)
  analyzer.py     анализ: приоритеты, связанные ошибки, проверки параметров
  report.py       вывод в консоль, отчёты HTML/JSON
  elm.py          прямая работа с ELM327: CAN/K-line, поиск блоков, KWP2000/UDS, лог обмена
  protocol.py     разбор ответов ELM327, KWP2000, UDS; список разрешённых (читающих) запросов
tests/            тесты (pytest)
```

Добавить свой код в базу — допишите запись в `vito_diag/data/dtc_ru.json`:
```json
"P1234": {"description": "...", "severity": "medium", "advice": "...", "group": "engine"}
```

Запуск тестов: `pip install -r requirements-dev.txt && python -m pytest`.

> Программа — помощник для диагностики, а не замена сервису. Серьёзность и советы
> ориентировочные; окончательный диагноз ставьте с учётом проверок на машине.
