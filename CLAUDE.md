# vito_diag — контекст для Claude

Пользователь говорит по-русски; отвечай по-русски, коротко и практично.

## Машина

- Mercedes Vito **W639**, 2008 г., шильдик **111 CDI** → двигатель **OM646** (2.1 CDI).
- АКПП (скорее всего 5G-Tronic **722.6**), полный привод 4x4. На W639 2008 г. 4x4 —
  вероятно, переделка Oberaigner. Это не подтверждено: уточнить у пользователя, если важно.
- Разъём OBD (по фото, разъём стоит перевёрнутым): контакты **4, 5, 6, 7, 8, 9, 11, 14, 16**.
  6/14 — CAN, 7 — K-line, **8, 9, 11 — дополнительные линии Mercedes** (предположительно K-line).
  Замеры напряжений — в docs/ADAPTER_SWITCH.md; если пользователь их прислал, запиши сюда.

## Оборудование

- USB ELM327 + самодельный переходник: поворотный переключатель подаёт контакт машины
  7/8/9/11 на контакт 7 адаптера (docs/ADAPTER_SWITCH.md).
- Положение переключателя знает только пользователь: **спрашивай его** и передавай в `--line`.
  Просить переключить — только между запусками команд.

## Как работать с машиной

```
python -m vito_diag ports                                  # найти COM-порт
python -m vito_diag scan --port COMx                       # OBD-II двигатель + отчёт
python -m vito_diag ecu monitor --port COMx                # пассивно послушать CAN
python -m vito_diag ecu scan-all --port COMx --line 7      # найти блоки CAN + K-line (конт. 7)
python -m vito_diag ecu scan-kline --port COMx --line 9    # K-line через переключатель
python -m vito_diag ecu read --port COMx --kline 10        # идентификация + ошибки блока
python -m vito_diag ecu raw "1A 86" --port COMx --can 7E0  # свой запрос
```

- Весь обмен с адаптером — в `logs/elm_*.log`, результаты опроса — в `reports/modules_*.json`.
  Непонятные ответы разбирай по логу и дорабатывай парсеры в `vito_diag/protocol.py`.
- scan-kline по всем адресам идёт 10–20 минут. Для повторов сужай диапазон `--addrs`.
- Найденные блоки (шина, линия, адрес, номер детали, что это за блок) записывай в раздел
  «Найденные блоки» ниже, чтобы не сканировать заново.
- Коды Mercedes, которых нет в базе, добавляй в `vito_diag/data/dtc_ru.json`, только если уверен
  в расшифровке. Иначе показывай сырой код и прямо говори, что расшифровка не подтверждена.

## Безопасность — обязательно

- **Только чтение.** Не используй `--unsafe`, не стирай ошибки (`clear`, сервисы 0x14/0x04),
  не отправляй запись/сброс/процедуры/прошивку (0x10 кроме штатной сессии, 0x11, 0x27, 0x2E,
  0x2F, 0x31, 0x3B, 0x34–0x37, 0x3D, 0x85, 0x28) без явной просьбы пользователя,
  подтверждённой после объяснения рисков.
- Долгий опрос с зажиганием садит АКБ: следи за напряжением (выводится при запуске `ecu`),
  при < 12,0 В предложи завести двигатель или подключить зарядку.
- При странном поведении машины — остановиться и попросить выключить зажигание.
